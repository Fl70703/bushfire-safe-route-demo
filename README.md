# Bushfire Demo

A lightweight React prototype for a UX and Product Design graduate portfolio. Figma is the source of truth for all product screens and visual decisions.

## Project structure

- `src/App.tsx` — assembles the prototype flow.
- `src/screens` — Figma-matched screens and states.
- `src/components` — reusable interface elements.
- `src/data` — local mock content only.
- `src/types` — shared TypeScript definitions.
- `src/assets` — exported Figma assets.
- `src/styles` — global and screen-level CSS.

## Commands

```bash
npm run dev
npm run build
npm run lint
```

Framer Motion will be added only when a specified interaction benefits from it.
